# Demo script (2 minutes, demo first)

Phone: Spanish UI, Do Not Disturb on, WhatsApp photo access set to **Ninguno** beforehand,
family contact chosen in onboarding, backend running, mirrored to the judges' screen.

| Time | Say (presenter) | Do (on the phone) |
|---|---|---|
| 0:00 | "Many Spanish-speaking grandparents in the US call a relative every time their iPhone needs a setting changed. Here's one: she wants to send photos to her grandkids on WhatsApp, but WhatsApp can't see her photos." | Lola's home screen showing. |
| 0:15 | "She just asks, in Spanish." | Tap and talk: "WhatsApp no ve mis fotos." Lola: "Quieres que WhatsApp pueda ver tus fotos. ¿Es así?" Tap **Sí**. |
| 0:30 | "She shares her screen through Apple's own sheet. Lola reads the text on the phone itself and throws each picture away." | Tap **Muéstrame tu pantalla** → consent → **Continuar** → start in Apple's sheet. (Rung B/C: skip, say "she can also send a screenshot".) |
| 0:45 | "She does every tap. Lola only talks." | Home → Ajustes. Lola: "Listo. Baja un poco y toca Privacidad y seguridad." Tap it. → "Toca Fotos." |
| 1:00 | "If she goes the wrong way..." | Tap **Localización** on purpose. Lola: "Eso es Localización. Toca la flecha de atrás y busca Fotos." Go back, tap **Fotos**, then **WhatsApp**. |
| 1:20 | "And if she's lost, she says so." | Say "estoy perdida". Claude re-explains in new words, with the exact label "Acceso completo". Tap it; confirm. |
| 1:30 | | Lola: "¿Ves una marca al lado?" → **Sí**. "Eso es todo. ¿Quieres mandarle un mensaje a tu familia?" → WhatsApp opens pre-filled; *she* taps Send. |
| 1:45 | "Claude understands her request and re-explains steps, but only from our curated library, and code checks every reply: real task, exact on-screen label, never a password or code. Cartesia gives Lola a calm Spanish voice. Screen text never leaves the phone." | Show the README "Where this could go wrong" table if asked. |
| 2:00 | "Lola: she does it herself, in her language." | |

## Backup plan
- Network fails → library-only replies and pre-rendered audio still work; keep going.
- Screen sharing fails → say "screen sharing is the experimental part" and use **Siguiente** (rung C) or a screenshot (rung B).
- Everything fails → play the recorded backup video (record it on the demo phone after rehearsal).

## Rehearse
Three full runs on the demo phone. Time each. Reset WhatsApp photo access to **Ninguno** between runs.
